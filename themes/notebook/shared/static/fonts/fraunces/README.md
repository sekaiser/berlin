# Fraunces headline fonts

Self-hosted Latin WOFF2 subsets from Google Fonts, v38, retrieved 2026-09-07.
Regular and italic: weight 400, optical size 9–144, SOFT 50, WONK 1.
The Latin subset includes German umlauts and common Western European characters;
unsupported characters use the CSS fallback font.

Design: Undercase Type, Phaedra Charles, Flavia Zimbardi.
