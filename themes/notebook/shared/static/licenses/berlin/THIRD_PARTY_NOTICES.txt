Deno-derived code
=================

Portions of the following Berlin files are adapted from Deno:

  util/file_watcher.rs  <- cli/util/file_watcher.rs
  util/logger.rs        <- cli/util/logger.rs
  colors.rs             <- runtime/colors.rs
  args/flags.rs         <- cli/args/flags.rs

Left-hand paths are relative to Berlin's cli directory. Right-hand paths
are relative to the Deno repository. The retained implementations were
compared with Deno v1.33.4:
https://github.com/denoland/deno/tree/v1.33.4
