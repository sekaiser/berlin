## Engineering desk

Original atmospheric illustration generated with the built-in image tool.
It depicts an imagined workspace, not Sebastian's actual desk. The transparent
PNG supplies the sharing image. The homepage uses its responsive WebP variants;
the shared `partials/engineering-desk.tera` supplies its image markup. Projects
provide their own surrounding copy and captions.

Prompt:

Use case: illustration-story.
Asset type: editorial illustration for an engineer's personal web journal, placed beside an article opening.
Primary request: a small quietly inhabited engineering desk, observed with affection, with subtle Studio Ghibli background-art influence and Japanese compositional restraint. Original scene, no existing characters.
Subject: an ordinary wooden desk, an open working notebook, pencil, compact dark computer screen with a few abstract unlettered lines, olive-green adjustable task lamp. No person. A fragment of window light falls across the objects.
Style/medium: fine irregular graphite contours and confident restrained gouache/watercolor areas; beautifully observed materials, not geometric vector icons, not photorealistic, no grunge or paper texture overlay.
Composition: one coherent intimate three-quarter desk vignette, not a room panorama; distinctive readable silhouette. Square canvas with generous clear margins; objects isolated on a genuinely transparent background, no rectangular frame or filled backdrop.
Color palette: warm ivory, honey wood, deep forest ink, olive, one small burnt-rust accent, cool blue-grey shadows.
Mood: quiet curiosity, useful tools, ordinary work; not twee, fantasy, retro steampunk or a generic startup illustration.
Constraints: no text, no handwriting, no labels, no watermark, no logos, no characters, no scattered symbols, no invented technical diagram. Final output a transparent PNG illustration.
