* Nested architecture

The grouping distinguishes authoring inputs, document processing, and outputs.
Arrows cross the group boundaries without crossing labels.

#+CAPTION: Two source formats share a processing stage and produce two outputs.
#+ATTR_HTML: :alt Nested architecture: Org and Markdown enter Parse, then Transform, which branches to HTML and a text draft.

* State machine

The retry edge returns a failed attempt to the ready state. Completion is a
separate accepting state; the running state also has a self-loop.

#+CAPTION: An illustrative execution lifecycle with success and retry paths.
#+ATTR_HTML: :alt State machine: Ready starts Running; Running can wait, fail into Failed, or finish in Done; Failed retries Ready.
[[file:states.svg]]

* Mathematical drawing

For the parabola \(f(x)=x^2\), the tangent at \((1,1)\) has slope two.
The shaded area from zero to one equals \(\frac{1}{3}\). The clipping boundary
limits the curve and tangent to the plotting region.

#+CAPTION: A parabola, its tangent at one, and the area under the curve from zero to one.
#+ATTR_HTML: :alt Mathematical plot: y equals x squared, tangent y equals two x minus one at (1,1), with area one third shaded under the curve between zero and one.
[[file:mathematics.svg]]

#+name: nested-architecture
#+begin_src latex :file architecture.svg :results file graphics :eval never-export :headers '("\\usepackage{tikz}")
\usetikzlibrary{arrows.meta,positioning,fit,backgrounds,calc}
\begin{tikzpicture}[
  font=\sffamily\large,
  box/.style={draw=black!65, fill=white, rounded corners=2pt,
              minimum width=25mm, minimum height=9mm},
  group/.style={draw=black!40, rounded corners=5pt, inner sep=5mm},
  flow/.style={-{Stealth[length=2mm]}, thick, black!75}]
  \node[box] (org) at (-1.65,0) {Org};
  \node[box] (md) at (1.65,0) {Markdown};
  \node[box, minimum width=38mm] (parse) at (0,-2.1) {Parse};
  \node[box, minimum width=38mm, below=7mm of parse] (map) {Transform};
  \node[box] (html) at (-1.65,-5.8) {HTML};
  \node[box] (text) at (1.65,-5.8) {Text draft};
  \begin{scope}[on background layer]
    \node[group, fit=(org)(md), fill=green!7,
          label={[font=\sffamily\small]above:Authoring}] {};
    \node[group, fit=(parse)(map), fill=orange!9,
          label={[font=\sffamily\small]right:Core}] {};
    \node[group, fit=(html)(text), fill=blue!5,
          label={[font=\sffamily\small]below:Publishing}] {};
  \end{scope}
  \draw[flow] (org.south) -- ($(parse.north)+(-.8,0)$);
  \draw[flow] (md.south) -- ($(parse.north)+(.8,0)$);
  \draw[flow] (parse) -- (map);
  \draw[flow] ($(map.south)+(-.8,0)$) -- (html.north);
  \draw[flow] ($(map.south)+(.8,0)$) -- (text.north);
\end{tikzpicture}
#+end_src

#+name: execution-states
#+begin_src latex :file states.svg :results file graphics :eval never-export :headers '("\\usepackage{tikz}")
\usetikzlibrary{automata,arrows.meta,positioning}
\begin{tikzpicture}[
  font=\sffamily\large,
  >={Stealth[length=2mm]},
  state/.style={circle, draw=black!65, thick, fill=green!7,
                minimum size=19mm},
  every edge/.style={draw, ->, thick, black!75}]
  \node[state, initial, initial text={}] (ready) at (0,0) {Ready};
  \node[state] (running) at (0,-2.4) {Running};
  \node[state, fill=orange!12] (failed) at (2.7,0) {Failed};
  \node[state, accepting, fill=blue!7] (done) at (2.7,-2.4) {Done};
  \path (ready) edge node[left, font=\sffamily\small] {start} (running)
        (running) edge[loop below] node[font=\sffamily\small] {wait} (running)
                  edge node[below, font=\sffamily\small] {finish} (done)
                  edge node[sloped, above, font=\sffamily\small] {fail} (failed)
        (failed) edge[bend right=25] node[above, font=\sffamily\small] {retry} (ready);
\end{tikzpicture}
#+end_src

#+name: parabola-and-tangent
#+begin_src latex :file mathematics.svg :results file graphics :eval never-export :headers '("\\usepackage{tikz}")
\usetikzlibrary{arrows.meta}
\begin{tikzpicture}[x=2.2cm, y=1.65cm, font=\Large, >={Stealth[length=2mm]}]
  \begin{scope}
    \clip (-.5,-.45) rectangle (2.15,2.75);
    \draw[step=.5, black!12, very thin] (-.5,-.45) grid (2.15,2.75);
    \fill[green!18] (0,0) -- plot[domain=0:1, samples=40] (\x,{\x*\x}) -- (1,0) -- cycle;
    \draw[green!40!black, very thick] plot[domain=-.5:1.7, samples=80] (\x,{\x*\x});
    \draw[orange!70!black, thick] plot[domain=-.5:2, samples=2] (\x,{2*\x-1});
    \draw[dashed, black!60] (1,0) -- (1,1) -- (0,1);
  \end{scope}
  \draw[->, thick] (-.5,0) -- (2.3,0) node[right] {$x$};
  \draw[->, thick] (0,-.45) -- (0,2.9) node[above] {$y$};
  \foreach \x in {1,2} {
    \draw (\x,.05) -- (\x,-.05) node[below] {$\x$};
  }
  \foreach \y in {1,2} {
    \draw (.04,\y) -- (-.04,\y) node[left] {$\y$};
  }
  \fill[black!80] (1,1) circle[radius=1.8pt];
  \node[above left] at (1,1.05) {$(1,1)$};
  \node[green!40!black, above left] at (1.65,2.75) {$f(x)=x^2$};
  \node[orange!70!black, right, align=left] at (1.65,1.75) {$f'(1)=2$};
  \node[green!30!black] at (.7,.2) {$\frac{1}{3}$};
\end{tikzpicture}
#+end_src
